    Processed subscriptions - Invoices and Quotes

    All invoices and quotes processed using the Process subscriptions option, will be generated as unposted documents. 

    Invoices - These Invoices is not updated (posted) to the ledger. 

    Quotes - The quotes is not yet confirmed (converted to an invoice). 

    Invoices

    These Invoices is not updated (posted) to the ledger. Before you update (post) these invoices generated by the process subscriptions to the ledger, you may need to edit these Invoices. 

    Once you are satisfied, you may proceed to update (post) these invoices to the ledger.

    Invoice form

    To select an Invoice:

    On the Documents (Default ribbon), select Invoices. 

    You may need to select the document status as "Unposted" and use the filtering and sort options on the documents grid to search and filter for specific documents.

    Click on Edit button to open the invoice form.  (Alternatively, you may double-click on the invoice). 

    You may need to focus on the following: 

    • Document header
      • Your reference - The first line of the "Reference" field will be included for example "Monthly rental" of the first subscription on the list. You may change this, as necessary.
      • RUN - Underneath the email address of the debtor form's document header will be generated, for example,  'RUN:20231001202321031'.
      • Messages - The default message lines as selected for the Invoices on Documents setup (Setup ribbon) , is not included in the Document header. You may add up to 3 lines of your own messages. 
      • Salesperson -  The default salesperson as set in the debtor (customer (client) account, will be displayed. You may change this, if needed.
      • Document group 1 / Document group 2 - If no document groups is selected, you may select the appropriate groups. 
    • Document lines 
      • Comments - Comments is automatically generated if the "Add description" on the Setup subscriptions is selected. If not selected, no comments will be inserted.

    Quotes

    Quotes will be generated if Quotes is selected on the Process subscriptions option.

    The quotes is not yet confirmed (converted to an invoice). Before you confirm (convert to an invoice) these quotes generated by the process subscriptions to the ledger, you may need to edit these quotes. 

    Once you are satisfied, you may proceed to confirm (convert to an invoice). Once these quotes is confirmed you may proceed to update (post) the converted quotes as invoices to the ledger.

    Quote form

    To select a Quote:

    On the Documents (Default ribbon), select Quotes. 

    You may need to select the document status as "Open"  and use the filtering and sort options on the documents grid to search and filter for specific quotes.

    Click on Edit button to open the quote form.  (Alternatively, you may double-click on the quote). 

    You may need to focus on the following: 

    • Document header
      • Your reference - The first line of the "Reference" field will be included for example "Monthly rental" of the first subscription on the list. You may change this, as necessary.
      • RUN - Underneath the email address of the debtor form's document header will be generated, for example,  'RUN:202308012023010801'.
      • Messages - The default message lines as selected for the quotes on Documents setup (Setup ribbon) is not included in the Document header. You may add up to 3 lines of your own messages. 
      • Salesperson -  The default salesperson as set in the debtor (customer (client) account, will be displayed. You may change this, if needed.
      • Document group 1 / Document group 2 - If no document groups is selected, you may select the appropriate groups. 
    • Document lines 
      • Comments - Comments is automatically generated if the "Add description" on the Setup subscriptions is selected. If not selected, no comments will be inserted.
